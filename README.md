# Sports Arena Reservation Website

## 📖 Description

This project is a web-based reservation application developed for Kharisma Sports Arena. The system allows users to book sports facilities online and helps administrators manage reservations efficiently.

---

## ✨ Features

### User
- User registration and login
- Online reservation booking
- View booking schedules
- Manage user account

### Admin
- Manage reservation data
- Manage users
- Monitor booking schedules

---

## 🧰 Technologies Used

- HTML

- Bootstrap

## ▶️ Run the Application

1. Start Apache and MySQL from XAMPP.
2. Import the database into phpMyAdmin.
3. Open the project in browser:

```plaintext
http://localhost/project-folder-name
```
